# Blog

Jekyll site for GitHub Pages.

- Posts live in `_posts/` as `YYYY-MM-DD-slug.md`.
- Interactive pages live in `assets/visualizers/`; embed one in a post with
  `{% include visualizer.html src="tile-walk.html" title="Kernel 2 Tile Walk" %}`.
- Local preview: `bundle install`, then `bundle exec jekyll serve`, and open http://127.0.0.1:4000.
